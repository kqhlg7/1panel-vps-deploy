## 什么样的 VPS 能装 1Panel：先把配置核对清楚

门槛不高。官方要求是主流 Linux 系统、1GB 内存、能联网，外加 root 或 sudo 权限。拆开看：

| 项目 | 最低要求 | 建议配置 |
| --- | --- | --- |
| 系统 | Ubuntu 20.04+ / Debian 11+ / CentOS 8+ / Rocky Linux 9+ | Debian 12，稳定且轻量 |
| 内存 | 1GB | 2GB 以上 |
| 磁盘 | 10GB 可用空间 | 按要跑的应用算 |
| 权限 | root 或 sudo | — |

几个挑机器时的实际情况：

- **内存**：1Panel 面板本身不重，重的是 Docker。应用商店里装的每个东西（Nginx、MySQL、WordPress）都是一个容器，比原生安装略吃内存。1GB 跑面板没问题，要正经建站跑数据库，2GB 更稳；内存紧张的机器可以开 swap 撑一下。
- **架构**：尽量选 KVM 架构的 VPS。老式 OpenVZ 机器内核限制多，装 Docker 容易出各种奇怪问题。

## 安装前：两分钟准备

SSH 登录服务器后做两件事：更新系统、装上 curl 和 wget。Debian 12 的最小安装镜像经常连 curl 都没有，跳过这步，后面执行脚本会直接报错。

bash
# 切换到 root（已经是 root 可跳过）
sudo -i

# 更新系统
apt update && apt upgrade -y

# 安装 curl 和 wget
apt install curl wget -y


CentOS 或 Rocky 把 `apt` 换成 `dnf`（或 `yum`）就行。系统版本是装机时选的，选成了不支持的版本也不用心疼，商家后台基本都有一键重装。

## 一条命令安装 1Panel

核心就是这条官方脚本：

bash
bash -c "$(curl -sSL https://resource.1panel.pro/v2/quick_start.sh)"


机器在国内、这条脚本连不上时，换备用地址：

bash
bash -c "$(curl -sSL https://resource.fit2cloud.com/1panel/package/v2/quick_start.sh)"


脚本跑起来后会依次问你几个问题，每个都值得说清楚：

1. **语言**：可选中文或英文，按习惯来。
2. **安装目录**：默认 `/opt/1panel`，直接回车。
3. **端口**：默认是随机生成的端口，想自己定（比如 10086）也行。务必记下来，这是之后登录面板的入口之一。
4. **安全入口**：一段附加在访问地址后面的后缀路径。作用是让扫描器找不到你的面板登录页，设一个自己记得住的就行。
5. **Docker**：脚本检测到机器上没装会自动帮你装。国内机器还会提示配置镜像加速——这是 1Panel 对国内用户相当实在的一点，拉镜像超时的问题它直接替你处理了，不用自己去改 daemon.json。
6. **面板用户名和密码**：设一个强密码。

看到满屏 Success 和面板地址就装完了。脚本本身一分来钟，算上装 Docker 一般也就两三分钟。屏幕上显示的面板地址、用户名、密码，全部抄下来或者截图。

## 装完先别关终端：三件事

1. **放行端口**。用了云服务商安全组的（阿里云、腾讯云这类），去控制台把刚才设置的端口放行，否则浏览器里永远打不开面板。
2. **访问面板**。浏览器输入 `http://服务器IP:端口/安全入口` 登录。
3. **把登录信息存好**。面板地址、账号、密码，缺一样都够你折腾。

真忘了也不慌，SSH 里跑一条命令就能找回全部访问信息：

bash
1pctl user-info


它会列出面板地址、端口、安全入口和账号凭据。这条命令能救急，但救不了图省事设弱密码的后果，密码还是设复杂点。

## 登录后先做这几件事

第一轮设置建议按这个顺序来：

1. **安全加固**：面板设置的安全选项里可以开启两步验证（TOTP）、配置 IP 白名单。面板是对公网开放的，这几项至少做一项。
2. **绑定域名 + HTTPS**：面板设置里可以直接绑定一个域名（比如 panel.yourdomain.com），用 Let's Encrypt 签发证书。选 DNS 验证的话，去域名服务商那里加一条 TXT 记录就能通过，之后用域名走 HTTPS 访问，不用再记裸 IP。
3. **装 OpenResty**：不管建什么站，Web 服务都得有。应用商店里点安装，几秒拉完镜像，记得勾选暴露 80 和 443 端口，不然外面访问不到你的站。
4. **试装一个应用**：应用商店里有 165+ 个常用开源应用（Nextcloud、Bitwarden、Umami、NocoBase 等）。以 WordPress 为例：装好 OpenResty 和 MariaDB 之后，在网站页面新建站点、选 WordPress 应用、填域名，再配一张 Let's Encrypt 证书就能上线。数据库和应用之间走 1Panel 自动创建的内部网络，默认不对外暴露端口，新手不用操心网络隔离的配置。

顺带一提，v2 版面板还内置了 AI 相关能力，可以直接部署 Ollama 跑本地模型、部署 OpenClaw 智能体，带 GPU 的机器还能监控利用率。用不上就当它不存在，不影响其他功能。

## 1Panel 和宝塔比，差在哪

架构。宝塔把 Nginx、MySQL 这些软件直接装进系统，依赖、日志、临时文件都留在宿主环境，装多了容易出依赖冲突和端口打架；1Panel 上的应用全是 Docker 容器，互相隔离，不要了就删容器，系统本身基本不留痕迹。打个比方，一个是装修队进场施工，一个是买成品家具，搬走就完事。

| 对比项 | 1Panel | 宝塔 / aaPanel |
| --- | --- | --- |
| 部署方式 | Docker 容器化 | 传统方式，依赖宿主环境 |
| 应用隔离 | 容器隔离，卸载不残留 | 共享环境，一个应用出问题可能波及其他 |
| 价格 | 核心功能开源免费 | 基础功能免费，高级功能收费 |
| Docker 镜像加速 | 内置，国内机器开箱即用 | 需自行配置 |

客观说一句，宝塔没有想象中那么不堪。机器上已经跑着一堆非容器化老业务、自己也用惯了的，没必要为了“干净”强行迁移。1Panel 更适合新开的机器，或者被 Docker 拉镜像超时折磨过的国内用户。

## 常见问题

**1GB 内存真的够吗？**
装面板够。要在同一台机器上跑 MySQL 加 WordPress 这套组合，建议 2GB，或者开 swap。RackNerd 的入门方案里两个档位都有，👉 [对照配置要求挑一台合适的](https://bit.ly/my-rn)。

**机器上已经装了 Docker，会冲突吗？**
不会。脚本检测到已有 Docker 会直接使用，不会重复安装。

**忘了面板密码、端口或安全入口？**
SSH 里执行 `1pctl user-info`，所有登录信息都在里面。

**1Panel 会不会把系统搞乱？**
它管理的应用都跑在容器里，删掉应用不残留依赖，面板自身文件集中在安装目录下，想彻底移除删目录就行。

**国内机器拉镜像超时怎么办？**
1Panel 内置了 Docker 镜像加速，装面板时按提示配置好即可，一般不需要自己折腾镜像源。
